# SkaFld VC in Muse

The skills and agent procedures are written for Claude Code. In Muse Code, read them with these substitutions.

| The text says                                                                          | In Muse                                                                                                                                                                                                                        |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Load `skafld-vc:<skill>` with the Skill tool                                           | `read_skill` with `skafld-vc:<skill>`, or read `skills/<skill>/SKILL.md`. The person can type `/skafld-vc:<skill>`.                                                                                                            |
| Start the `skafld-vc:<agent>` agent (the Agent tool)                                   | Muse runs no agents from plugins. Follow `skills/ask/references/<agent>.md` yourself, here; where a subagent tool is available, give it that file and the request.                                                             |
| `deliverables:<tool>`, `setup:<tool>`                                                  | `mcp__plugin_skafld_vc_deliverables__<tool>`, `mcp__plugin_skafld_vc_setup__<tool>`                                                                                                                                            |
| `exa:<tool>`, `apollo:<tool>`, other connectors, and `skafld-vc:<tool>` (the platform) | Only when the person added the server to `~/.config/muse/settings.json` (a `streamable-http` entry with its URL; the platform's is `<platform address>/api/mcp`) and signed in with `muse mcp login <name>` where it needs one |
| `${CLAUDE_SKILL_DIR}`                                                                  | The folder of the skill you are following, inside the installed plugin                                                                                                                                                         |
| Run `python3 <script>`                                                                 | `bash`, always as `python3 <script>`                                                                                                                                                                                           |
| Ask the person                                                                         | `request_user_input`                                                                                                                                                                                                           |

The plugin declares only the deliverables and setup servers, which start after `muse plugins approve skafld-vc`. Exa, Apollo and the other connectors are recommended, not part of the plugin: use one only when the person added it to their Muse settings. The deliverables and setup servers need Node.js 18 or later on the PATH; without Node, they do not start, so follow the skills' steps for when those servers are not available.
